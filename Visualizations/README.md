# Visualizations

This folder contains charts created from the analysis.

## Included Visualizations

### Top Performing Franchises
Shows which franchises most consistently produced elite scorers.

### Rookie vs Veteran Comparison
Compares scoring, rebounding, and assists between rookies and veteran players.

### Usage vs Efficiency
Examines whether high-volume scorers sacrifice shooting efficiency.

### NBA Player Size Trends by Decade
Illustrates how player height and weight have evolved over time.

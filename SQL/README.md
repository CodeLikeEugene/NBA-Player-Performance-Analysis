# SQL Analysis Scripts

This folder contains the SQL scripts used to answer the business questions explored in this project.

## Scripts Included

### 01_season_leaders.sql
Identifies the highest scorers, rebounders, and assist leaders for each NBA season.

### 02_usage_vs_efficiency.sql
Evaluates whether high-volume scorers sacrifice shooting efficiency.

### 03_most_improved_players.sql
Identifies the players with the largest year-over-year scoring improvements.

### 04_era_analysis.sql
Analyzes player height and weight trends across NBA decades.

### 05_franchise_analysis.sql
Determines which franchises consistently produce elite performers.

### 06_rookies_vs_veterans.sql
Compares the contributions of rookies and veteran players.

### 07_data_mvp.sql
Calculates a custom MVP score using a weighted performance model.

### 08_dream_team.sql
Builds a data-driven NBA Dream Team based on statistical excellence.
